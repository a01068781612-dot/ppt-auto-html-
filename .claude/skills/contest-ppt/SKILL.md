# 대회 발표 PPT 제작 규칙

## 0. 먼저 읽을 것
1. `발표/<YYMMDD>_<대회명>/대회정보_v.*.md` (최신) — 없으면 `발표/대회정보_양식_v.*.md`를 복사해 폴더를 만들고, 강사에게 빈칸을 묻는다
2. 같은 폴더의 `자료/` (요강·기획서·시연 영상·캡처·사진)
3. `PPT디자인시스템_v.*.md` (최신) — 색·글꼴·사각 장식·화면 유형·모션 레시피·제작 파이프라인
4. `.claude/skills/dark-motion-ppt/SKILL.md` — 공통 규칙
5. 폴더에 진행요약이 있으면 최신 것부터 (이어서 하는 작업)

## 1. 폴더와 문서
`발표/<YYMMDD>_<대회명>/` 안에 버전 파일로 만든다(versioned-files 규칙).
- `<대회명>_기획안_v.1.0.0(YY.MM.DD).md` — 심사 기준 ↔ 화면 대응표, 화면 목록, 발표 시간 배분
- `<대회명>_진행요약_v.1.0.0(...)md` — 결정 사항·남은 일 (결정이 바뀔 때마다 새 버전)
- `<대회명>_진행순서표_v.*.md` — 장 · 화면 · 할 말 · 누적 시간(문서에만, 화면에는 시간 표기 금지)
- 제작소스는 루트의 `제작소스_v.*`를 `발표/<...>/제작소스_v.1.0.0(...)/`로 복사해서 내용만 바꾼다

## 2. 구성 (심사 기준 순서가 우선)
요강의 심사 기준 순서·배점에 맞춰 장 수를 배분한다. 기본 뼈대:

| 순서 | 내용 | 쓸 화면 유형(디자인시스템 2장) |
|---|---|---|
| 1 | 표지 (과제명, 발표자/팀 — 익명 심사면 이름·소속 빼기) | 표지 |
| 2 | 목차 (심사 기준 순서) | 목차 |
| 3 | 문제·현황 (숫자) | PART 인트로 + 타임라인/비교표 |
| 4 | 원인 | 정리(카드 3) |
| 5 | 해결 방법 (시스템 개요) | 계단(지도) 또는 정리 flow(→) |
| 6 | 시연 | 영상 소개 → 🎬 본인 시연 영상(전체화면 자동 재생) |
| 7 | 효과 (정량 → 정성) | 정리 + 큰 숫자(카운트업) |
| 8 | 차별성 | 비교표(기존 vs 우리) |
| 9 | 확산·지속 계획 | 타임라인 |
| 10 | 마무리 한 문장 | 마무리 |
| 11 | Q&A | Q&A |

- 장 수 기준: 발표 시간(분) × 1.5~2장. 시연 영상 길이는 따로 뺀다
- 같은 화면 유형·모션 효과가 연달아 나오지 않게 섞는다

## 3. 강의용과 다르게 할 것
| 항목 | 대회 기준 |
|---|---|
| 용량 | 요강의 제한 확인. 유튜브·외부 영상은 넣지 않음. 모션은 `--crf 24~28`, 시연 영상은 720p로 줄여 제한 안에 맞춤 |
| 저작권·초상권 | **남의 영상·기사 사진·인물 사진 금지**(허락받은 것만). 언론 보도는 제목과 출처만 텍스트로. 본인 화면·데이터 위주 |
| 개인정보 | 화면 캡처 속 이름·연락처·민원 내용은 가림 |
| 익명 심사 | 표지·Q&A·파일명에서 이름·소속·연락처 제거 |
| 예비본 | 심사장 PC에서 영상이 안 돌 수 있음 → **PDF(각 장 마지막 장면)** 와 **MP4(전체 발표 흐름)** 를 함께 만든다 |
| 파일명 | 요강의 파일명 규칙이 있으면 그것을 따르고, 작업 폴더에는 버전 파일명으로도 보관 |
| 글자 수정 | 모션 화면은 영상이라 PPT에서 고칠 수 없음 → 문구 확정 전에 미리보기로 충분히 확인받기 |

## 4. 진행 순서
1. 대회정보 확인 → 빈칸 질문(요강·심사 기준·발표 시간·제출 형식은 필수)
2. 기획안 v.1.0.0: 심사 기준 ↔ 화면 대응표 + 화면 목록 → 강사 확인
3. 모션 HTML 생성 → `sqfix.py` → `allshot.js`로 **미리보기 이미지 먼저 전달** (PPT는 확인 후)
4. 렌더(`--crf 24`) → `build.js` → `timing.py` → validate → LibreOffice 미리보기
5. 전달: 30MB 넘으면 29MB 조각 + `0_합치기.bat`(조각 크기 확인). 일부 장만 바뀌면 교체용 PPT(`ONLY=`)
6. 예비본 PDF·MP4, 필요하면 예상 질문·답변(competition-qa 스킬) · 시간 맞춘 발표 대본
7. 진행요약·진행순서표 새 버전 저장, git에는 문서·스크립트만(영상·사진·PPT 제외)
