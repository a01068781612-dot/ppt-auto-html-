# 분해판(글자 수정 가능) PPT 만들기

## 0. 먼저 읽을 것
1. **`편집용PPT_점검표_v.*.md`(저장소 루트, 최신)** — 사용자가 지적했던 것 전부. **프리뷰를 주기 전에 한 줄씩 확인한다.**
2. `PPT디자인시스템_v.*.md` — 의미 단위 줄바꿈, 여백이 한쪽에 몰리지 않게, 색 · 글꼴
3. 진행 중인 강의 폴더의 최신 진행요약(이전 버전 · 결정 사항)
4. versioned-files 스킬 — 결과 파일은 새 버전 이름으로

## 1. 만드는 순서 (`scripts/make_editable.sh` 한 번에)
| 단계 | 스크립트 | 하는 일 |
|---|---|---|
| ① 카드 글자 맞춤 | `fit_cards.js` | 한 줄에 들어가는 `<br>` 없앰 · 카드 폭에 맞게 최대 1.45배 · 나란한 카드 머리글 맨 위 · 칸 높이 맞춤 · 같은 배율 · 의미 단위 줄바꿈 · 작은 글씨 5단계(18·22·26·30·34px) · 한글 작은 글씨 자간 0 · 가로 flex 문장 한 덩어리 |
| ② 손볼 장 | `<작업 폴더>/fix.js`(있으면) | 사용자가 지목한 장만 직접 고침(예: `강의/261023_…/제작소스_v.1.0.0(26.10.15)/fix_75_84_99_117.js`) |
| ③ 본문 굵기 | `semibold.js` | Regular(400) → SemiBold(600). 줄 수 · 줄 시작 위치 · 상자 위치가 하나라도 바뀌면 자간(최대 0.06em) · 나란한 칸 간격으로 보정, 안 되면 그 덩어리만 400 |
| ④ 장면 그림 | `shot_all.js` | 맞춘 HTML을 1920×1080으로 찍음(사진 모서리 채우기 · 프리뷰용) |
| ⑤ 분해 | `split_extract.js` → `split_prep.py` → `ghost_extract.js` | 도형 · 사진(보이는 부분만) · 장식 PNG · 외곽선 글자 · 글상자(줄마다 왼쪽 위치 = 둘째 줄 들여쓰기) |
| ⑥ 조립 | `split_build.js` → `split_titles.py` | pptxgenjs로 PPT, 슬라이드 이름 "번호. 제목" · 제목 자리 · 테마 글꼴 Pretendard · 외곽선 글자 noFill · 들여쓰기 marL |
| ⑦ 검사 | `check_text.js` · `check_pptx.py` | 원본과 글자 대조(다른 장 0), 글꼴 · 이름 · 영상 · 테마 확인 |

- `split_build.js` 맨 위의 `VIDEO`(영상 자리 장) · `ART`/`LINKS`(원문 링크) · `NAME_FIX` · `SECTION`은 강의마다 고친다.
- 7초짜리 모션 장면(오프닝 · 강사 소개)은 영상으로 두지 말고 `ws_static.py`처럼 정적 장면 HTML로 다시 만들어 분해한다.
- 사진 원본이 작으면(공문 속 사진 등) `esrgan.py`(Real-ESRGAN x4plus, 이 PC에서 처리)로 키운다. 외부 서비스에 올리지 않는다. 얼굴이 바뀔 수 있으니 반드시 비교 그림을 먼저 보여 준다.
- 큰 영상은 PPT에 넣지 않고 첫 화면만 둔다. 영상은 `N.이름_N번슬라이드.mp4`로 따로 담는다(녹화 프로그램 창 · 광고가 보이는 앞뒤는 잘라냄).

## 2. 프리뷰 → 승인 → 전달
1. 고친 장만 **3×3 프리뷰**(장 번호 표시)로 준다. 글꼴 · 굵기처럼 전체가 바뀌면 전체 120장 3×3.
2. 사용자가 고칠 장을 말하면 **그 장만** 고치고 다시 프리뷰(다른 장이 같이 바뀌면 바뀐 장도 알려 줌).
3. 승인 후에만 새 버전 저장 → zip → ff 깃(`hyperframes-ffmpeg` `handoff/…` 브랜치, 같은 폴더의 이전 버전은 지움) → ff 세션에 알림 → 진행요약 새 버전.
4. zip 구성(폴더 이름은 사용자가 정한 것 그대로, 예 `광주소방학교_직장훈련특강_261023/`):
   - `00_먼저읽기.txt`(UTF-8 BOM · CRLF) — 버전 · 고친 것 · 글꼴 설치 방법
   - `1_PPT/` · `2_글꼴_Pretendard/`(7개) · `3_영상(따로 넣을 큰 영상)/`(+ `00_영상목록.txt`)
   - 파이썬 zipfile로 묶음(한글 이름 UTF-8), mp4 · pptx는 압축 안 함, `testzip()` 확인

## 3. 답할 때
- 질문에 "답만 줘"면 표 하나 · 몇 줄로 끝낸다. 근거(공문 번호 · 파일)는 붙이되, 확인 못 한 것은 못 했다고 말한다.
- 글꼴 문의: PPT 안 글꼴을 직접 조회해서 답한다(장마다 latin · ea 글꼴, PDF로 바꿔 `pdffonts`). 구글 미리보기 · 글꼴 미설치 PC에서는 다르게 보인다는 점을 함께 말한다.
