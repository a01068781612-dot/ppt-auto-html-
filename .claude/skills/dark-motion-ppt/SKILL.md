# 다크 모션 PPT 제작 규칙

새 주제의 PPT도 **디자인·모션·제작 방식은 그대로**, 내용만 바꿔서 만든다.

## 먼저 읽을 것
1. `PPT디자인시스템_v.*.md` (최신) — 색·글꼴·사각 장식·화면 유형 18가지·모션 레시피·제작 파이프라인·콘텐츠 입력 양식·점검표
2. `제작소스_v.*/README.md` — 스크립트 위치와 실행 방법
3. 참고 작품 기록: `AI특강_작업이력_v.*.md` (무엇을 왜 고쳤는지 — 같은 실수 반복 금지)

## 새 강의 시작할 때
- 강의마다 폴더를 따로 만든다: `강의/<YYMMDD>_<강의이름>/` — 그 안에 기획안·진행요약·진행순서표·작업이력을 새로 시작한다(v.1.0.0). 기존 AI특강 문서는 고치지 않는다.
- 강사에게 받을 것: 주제·대상·분량·파트 구성·영상·기사·사진·강사 소개 자료. 모르는 것은 디자인시스템 6장 "콘텐츠 입력 양식" 기준으로 묻는다.
- 제작소스는 새 폴더로 복사해서 쓴다(`강의/<...>/제작소스_v.1.0.0(YY.MM.DD)/`). 내용(JSON·표·build.js 순서)만 바꾸고 디자인 CSS·모션 코드·sqfix는 그대로 둔다.

## 꼭 지킬 것 (강사 확정 규칙)
- 영상은 무조건 전체화면, 소개 장 → 영상 장 자동 재생
- 화면에 시간(분·초) 표기 금지
- 사각 장식은 제목 첫 글자 대각선 왼쪽 위, 글자 쪽 모서리를 끊은 모양 (sqfix.py)
- 기사는 언론사 기사만, 제목·첫 문단에서 화제성이 보이는 것. 링크 목록 먼저 확인받기
- 장면마다 모션 효과를 다르게, 렌더는 `--crf 24`
- 먼저 미리보기 이미지 → 강사 확인 후 PPT를 29MB 조각 + `0_합치기.bat`(조각 크기 확인)으로 전달. 일부 장만 바뀌면 교체용 PPT
- 결과물은 버전 파일명 + `## 변경 이력` (versioned-files 스킬)
- 발표 대본은 `발표대본_작성가이드_v.*.md`를 따른다: 화면 문구 기준 2~5문장, 화면 문구만 굵게, 문장마다 줄바꿈, 표(장·⏱·화면·짚을 곳·대사), 모든 장 시작 시각 + 처음·중간·끝, 텍스트 확인 후 PDF(`script/md2pdf.py`)
- 영상·사진·PPT 파일은 git에 넣지 않는다(문서·스크립트만)
