# 현장 사례 PPT 만들기 (직장훈련 · 소방학교 · 사진 많은 PPT)

## 먼저 읽을 것
1. **`현장사례PPT_레퍼런스_v.*.md`(저장소 루트, 최신)** — 이 스킬의 기준 전부. 만들기 전에 1~5절을, 프리뷰 주기 전에 다시 한 번 확인한다.
2. `PPT디자인시스템_v.*.md` + `.claude/skills/dark-motion-ppt/SKILL.md` — 디자인 · 모션 · 제작 방식
3. 분해판(글자 수정 PPT)이면 `.claude/skills/editable-ppt/SKILL.md` + 최신 `편집용PPT_점검표_v.*.md`
4. 강의 폴더(`강의/<YYMMDD>_<강의이름>/`)의 최신 진행요약

## 시작할 때 꼭
- **사진 · 공문 그림을 모으면 먼저 저화질 목록부터 보고한다**(레퍼런스 P1): 화면에 놓일 크기보다 작은 원본을 장 번호와 함께 보여 주고, 더 큰 원본을 찾을지 · 이 PC에서 업스케일할지(`.claude/skills/editable-ppt/scripts/esrgan.py`) 사용자에게 묻는다.
- 장 구성을 정하면 장마다 유형(레퍼런스 6절)을 붙이고, 유형별 모션(4절)을 미리 적어 둔다.

## 만들 때 기준(요약 — 숫자는 레퍼런스)
- 꺾쇠: 위치 먼저(제목 첫 글자 왼쪽 위 45도, 간격 = 꺾쇠 × 0.46), 크기는 제목 글자 크기에 맞춤
- 꺾쇠 위 주황 머리표 간격 일정, 한 줄의 여러 덩어리는 간격 유지
- 흐린 영문 글자는 흰색 16% 채움 + 테두리 30%
- 같은 종류 카드는 같은 크기 · 같은 줄 높이, 계단 · 흐름 카드는 같은 구조 · 같은 위 간격
- 모션은 장 유형마다 다르게, 마지막 장면 = 원본 화면

## 보여 줄 때
- 3×3 프리뷰는 만든 PPT를 직접 렌더링한 그림(`soffice --headless --convert-to pdf` → `pdftoppm`)
- 시안은 실제 슬라이드에 넣어서, 전/후 비교로
- 지목한 것만 고치고 바뀐 장 목록을 숫자로 보고
- 순서: 확인 → 프리뷰 → 승인 → zip(쓰는 글꼴만) → ff 깃 → ff 세션 알림

## 새로 지적받으면
- `현장사례PPT_레퍼런스_v.*.md` 새 버전에 한 줄 추가하고(변경 이력 포함), 분해판 관련이면 `편집용PPT_점검표_v.*.md`에도 넣는다.
