## 1. 강의 방향
- 설명은 짧게, **영상 보고 → 폰으로 따라 하기 → 단톡방에 올려 같이 보기** 반복
- 교육생 앱: **Gemini + Flow** 두 개 (모두 무료, 구글 계정 하나)
- 강사가 먼저 폰으로 시연 → 폰 화면을 빔에 띄움 → 교육생 따라 하기
- 결과물은 **카톡 오픈채팅**에 올려 **사진·영상 전시회**
- 유료 기능(「작업」 모드 등)은 강사 시연만

## 2. 강사 화면 구성 (HDMI)
- 노트북 HDMI → 빔프로젝터 (디스플레이 「복제」)
- 노트북에 띄울 창 4개를 Alt+Tab으로 오감
  - ① PPT 슬라이드 쇼
  - ② **폰 화면** (스마트뷰)
  - ③ 카카오톡 PC (단톡방 — 전시회·투표)
  - ④ 크롬 (Claude 시연)
- **폰 화면 띄우기**
  - 주: 폰 **스마트뷰 → 노트북 「무선 디스플레이」** (와이파이 없어도 기기끼리 연결)
    - 노트북 준비(한 번): 설정 → 시스템 → 선택적 기능 → 「무선 디스플레이」 설치 → 「이 PC에 화면 표시」 켜기(PIN 끔) → 「무선 디스플레이」 앱 실행
    - 폰: 빠른 설정 → Smart View → 노트북 이름
  - 예비 1: 「휴대폰과 연결」(노트북) + 「Windows와 연결」(폰) → 휴대폰 화면
  - 예비 2: **USB 케이블 + scrcpy** (와이파이 무관, 지연 거의 없음)
- **멀티 컨트롤**(설치 완료): 노트북 키보드로 폰에 요청문 입력 · 폰에서 만든 사진·영상을 노트북으로 끌어와 **전체 화면 재생**(선명·소리 좋음)
- 폰: **방해 금지 모드**, 미리 로그인

## 3. 사전 안내 (담당자 통해 교육생 단톡방에 미리)
- 카톡 오픈채팅 입장 링크 (참여코드)
- 폰에 설치·로그인해 오기
  - **Gemini** 앱 (안드로이드는 대부분 기본 설치)
  - **Google Flow** 앱 (Play 스토어 / App Store 「Google Flow」)
  - 구글 계정 로그인 확인
- 당일 충전기·충분한 배터리

## 4-1. 블록 A — 정부는 지금 (♻️ 10.20 PART 2 기사)
- 🎬 국무회의 인트로(오프닝)에서 이어서 — “정부가 AI를 어떻게 보고 있나”
- 기사 순서: 정부 제도 → 지자체 인사 → 기관장 → 현장 공무원 → 한 사람이 바꾼 판
  1. **AI 잘 쓰는 공무원에 승진·포상 인센티브** — 5급 조기승진 성과심사에서 AI 챔피언 블랙 가점 (파이낸셜뉴스) ← **6급 중견리더에게 가장 와닿는 장**
  2. 경기도: AI 챔피언 블루·블랙에 실적 가산점 0.5점
  3. 병무청장이 AI 챔피언 직원들과 간담회
  4. 「AI로 일하는 공무원들」 (ZDNet)
  5. 7년차 공무원이 만든 AI가 판을 바꿨다 — 광진구청 (ZDNet)
- 강사 소개를 여기에 연결: “저도 그 AI 챔피언(BLACK) 과정입니다” → 수상·출강 한 장
- 마무리 한 줄: “그래서 오늘은 **폰 하나로 바로 써 보는 것**부터 합니다” → 블록 ①

## 5. 미션 1 — Gemini로 사진 바꾸기 (단계별)
- **강사 시연 → 따라 하기** (강사 폰 화면 띄움)
1. Gemini 앱 열기
2. 입력창 왼쪽 **「+」** → **「카메라」**(셀카 찍기) 또는 **「갤러리」**(사진 고르기)
3. 사진이 붙으면 입력창에 말하기
   - “**배경을 진주성 야경으로 바꿔 줘**”
   - “배경을 스페인 해변으로, 사람은 그대로”
   - “눈 오는 겨울 풍경으로 바꿔 줘”
4. 전송 → 10~20초 뒤 결과 사진
5. 마음에 안 들면 이어서 말하기: “조금 더 밝게”, “옷을 정장으로”
6. 결과 사진 누르기 → **다운로드(저장)** → 갤러리에 저장 (**미션 2에서 씀**)
7. 카톡 단톡방에 올리기 (원하는 분만)
- 보너스
  - “이 흑백 사진을 컬러로 복원해 줘” (옛날 가족사진)
  - “증명사진처럼” · “캐리커처로”
  - 사진 없이 글로: “23기 중견리더 수료 축하 포스터, 진주성 배경”
- 사진 전시회: 노트북 카톡 PC → 빔 → 올라오는 사진 소개
- 무료: 하루 약 20장 (1인 3~4장이면 충분)

## 6. 미션 2 — Flow 설치부터 영상 만들기 (단계별)
### 2-1. 설치·로그인 (7분)
1. Play 스토어(아이폰은 App Store)에서 **「Google Flow」** 검색 → 설치
   - 안 보이거나 설치 안 되면: 크롬에서 **labs.google/flow** 접속 (단톡방 공지 링크)
2. 열기 → **구글 계정 선택** (Gemini와 같은 계정)
3. 생년월일·약관 동의 (만 18세 이상)
4. 무료 크레딧 확인 (하루 50 — 빠른 영상 약 2편)

### 2-2. 사진으로 영상 만들기 (12분)
1. **「+」 새로 만들기**
2. **사진으로 시작** 선택 → 갤러리에서 **미션 1 결과 사진**
3. 움직임을 말로 쓰기
   - “사람이 웃으며 손을 흔들고, 카메라가 천천히 다가간다”
   - “눈이 내리고, 사람이 하늘을 올려다본다”
4. 품질은 **빠른(Fast/Lite)** 선택 → 크레딧 아끼기
5. 만들기 → **1~2분 대기** (그동안 바로 미션 3 OCR)
6. 완성 → 재생 → **다운로드** → 단톡방에 올리기
- 막히면
  - 크레딧 부족·혼잡: 강사 영상 보기 → 집에서 다시
  - Flow가 아예 안 되면: **구글 포토 → 「만들기」 → 「사진을 동영상으로」** (짧고 소리 없음)
- 메뉴 이름은 리허설 때 실제 화면 이름으로 맞춰 PPT·실습 카드에 반영

## 7. 미션 3 — 찍으면 글자가 된다 (Gemini OCR)
- **미션 3-1 화면 글자 찍기** (강사가 빔에 글 한 장을 띄움 — 예: 짧은 공지문·보도자료 한 문단)
  1. Gemini → 「+」 → **카메라** → 빔 화면(또는 노트북·모니터 화면) 찍기
  2. “**사진 속 글자를 그대로 적어 줘**” → 글자가 텍스트로 나옴
  3. 결과 길게 누르기 → **복사** → 카톡 단톡방에 **붙여 넣기** (손으로 칠 필요 없음)
  4. 이어서 말하기: “세 줄로 요약해 줘” · “공문체로 다듬어 줘” · “영어로 번역해 줘”
- **미션 3-2 종이 표 → 엑셀 표**
  1. **실습 카드 뒷면 표** 찍기
  2. “엑셀 표로 만들어 줘” · “민원 많은 3가지 요약해 줘”
- 업무로 잇기
  - 종이 공문·회의 자료 → 글자로 받아 보고서에 붙이기
  - 명함 → “이름·전화·메일만 표로”
  - 손글씨 메모 → 글자로 정리
  - 오래된 표 사진 → 엑셀
- 주의: **개인정보가 있는 서류는 찍지 않기** (보안 3원칙과 연결) · 숫자는 원본과 한 번 대조

## 8. 강사 시연

## 9. 블록 ⑦ — 공무원의 AI: 막힌 사이트와 정보보안 (10분)
### 9-1. 현실 — “사무실 PC에서는 왜 안 되나요?” (2분)
- 업무PC는 **업무망·인터넷망 분리** — 생성형 AI 사이트가 막힌 기관이 많음
- 그래서 오늘은 **개인 폰**으로 실습 → 하지만 **폰으로 해도 되는 것과 안 되는 것**이 따로 있음
- 질문 던지기: “사무실에서 챗GPT 열어 보신 분? 열리던가요?” (손들기)

### 9-2. 정부 방향 — 막는 것에서 「등급 따라 쓰게」로 (3분)
- **국가망보안체계(N2SF)** — 국정원 보안가이드라인 1.0 (2025. 9.)
  - 정보를 **기밀(C) · 민감(S) · 공개(O)** 세 등급으로 나눔
  - **공개(O) 정보는 승인된 생성형 AI로 처리 가능**, 민감·기밀은 엄격히 통제
  - 업무PC에서도 AI를 쓸 수 있게 하는 방향 — 기관별 도입이 진행 중
- 한 줄: “앞으로는 **‘쓰지 마라’가 아니라 ‘등급을 보고 써라’**”
- 정확한 기관 적용은 소속 기관 정보보안 담당·지침 확인 (기관마다 다름)

### 9-3. 내 폰에서 지킬 것 — 보안 3원칙을 등급으로 (3분)
| 넣어도 되는 것 (공개 O) | 넣으면 안 되는 것 (민감 S · 기밀 C) |
|---|---|
| 이미 배포한 보도자료 · 공개된 법령·지침 · 홈페이지 공지 | 민원인 이름·연락처·주민번호 · 내부 보고서 원문 · 결재 전 계획·예산 · 감사·인사 자료 |
- 오늘 실습과 연결
  - **미션 3 OCR**: 공문·서류를 찍기 전에 “이거 공개된 건가?” 먼저 — 개인정보가 보이면 찍지 않기
  - **단톡방**: 업무 자료·서류 사진 올리지 않기
  - **Gemini 앱 활동**: 설정에서 대화 기록·학습 사용을 끌 수 있음 (업무 비슷한 내용 물을 때)
  - 꼭 필요하면 **가명·요약**으로 바꿔서
- 리더 관점 한 줄: “직원에게 **쓰지 말라고 하기보다, 무엇은 되고 무엇은 안 되는지** 알려 주세요”

### 9-4. 미션 4 · O/X (2분)
- AI가 틀린 곳 찾기 3문제 → 정답 (♻️ 만든 장면) — “그래서 **숫자·출처는 사람이** 확인”
- 카톡 O/X 투표 4문항 (보도자료 O · 민원인 연락처 X · 공개 법령 O · 결재 전 예산안 X)
