## 장면별 대본
> 📷 = 찍을 장면 · 🎤 = 멘트 · 🔤 = 자막(편집 때) · ⏱ = 분량

### S1. 오프닝 훅 (아침, 집) ⏱ 15초
- 📷 거울 앞이나 책상 앞 셀카, 셔츠 단추 채우며
- 🎤 "오늘 6급 선배님들 50명 앞에서 AI 강의합니다. 저 소방교거든요… 떨립니다."
- 🔤 「소방교가 6급 선배님들 가르치러 갑니다」

### S2. 아침 준비 ⏱ 30초
- 📷 커피 내리기 → 셔츠·가방 (빠른 컷 4~5개)
- 🎤 "강의 날은 아침부터 리허설 한 번 하고 갑니다."
- 📷 노트북으로 PPT 넘기며 혼잣말 연습 (2배속)
- 🔤 「리허설 3번째」 「71장… 많다」

### S3. 짐 싸기 (책상 위에서 내려 찍기) ⏱ 30초
- 📷 하나씩 올려놓기: 노트북 → HDMI 케이블 → 충전기 → 리모컨 → 폰 → 보조배터리 → 삼각대 → 신분증
- 🎤 "이 중에 하나라도 빠지면 강의 망합니다. 특히 이거." (HDMI 클로즈업)
- 🔤 체크 표시 ✔ 하나씩 / 「신분증 = 방문증 받을 때 필요」

### S4. 출발 — 마산 ⏱ 20초
- 📷 현관 나서기 → 차 문 닫기 → 시동
- 📷 내비에 「경상남도청 서부청사」 입력 화면 클로즈업 (도착 예정 시간 보이게)
- 🎤 "마산에서 진주까지 한 시간. 출발합니다."
- 🔤 「마산 → 진주 · 약 1시간」 「강의까지 D-2시간 30분」

### S5. 고속도로 (운전 중) ⏱ 40초
- 📷 **거치대 고정** 정면 1컷 + 창밖 1컷 (녹화는 출발 전에 켜 두기, 운전 중 폰 조작 ✕)
- 📷 남해고속도로 표지판 · 「진주」 이정표 타임랩스 10초
- 🔤 「남해고속도로 타는 중」 「진주 ○km」
- ⚠ 운전 중 토크는 하지 말고, S6 휴게소나 신호 대기에서

### S6. 휴게소 토크 (함안휴게소 등) ⏱ 1분
- 📷 차에서 내려 간식 하나 사기 (호두과자·커피) → 차 안이나 벤치에서 먹으며 인터뷰
- 🔤 질문 자막을 띄우고 대답하는 형식
  - Q1 「오늘 뭐 가르쳐요?」 🎤 "폰으로 사진 만들고, 그 사진으로 영상 만드는 거요. 다 무료예요."
  - Q2 「공무원이 왜 공무원한테 배워요?」 🎤 "사무실 PC에서 AI 막혀 있는 거, 저도 똑같이 겪거든요. 그래서 이렇게 쓴다는 걸 알려 드리는 거죠."
  - Q3 「AI 챔피언 BLACK이 뭔데요?」 🎤 "행안부가 인증하는 AI 인재 등급인데, 제일 높은 게 블랙이에요. 강의 때 공개합니다."
- 🔤 「강의 전 당 충전」

### S7. 진주 도착 · 점심 ⏱ 1분
- 📷 「진주」 표지판 → 남강 풍경 3초
- 📷 진주냉면 또는 진주비빔밥 — 음식 클로즈업 → 한 입 → 한 줄 평
- 🎤 "진주 왔으면 이거 먹어야죠. 강의 전 든든하게."
- 🔤 「진주 명물 ○○」 「강의까지 D-1시간」

### S8. 서부청사 도착 ⏱ 40초
- 📷 건물 외관 와이드 → 입구로 걸어가기
- 📷 1층 로비 신분증 내고 방문증 받기 (손만, 방문증 번호 ✕)
- 🎤 "공무원인데 공무원 건물 들어갈 때 방문증 받아요." (웃음)
- 🔤 「경상남도청 서부청사」 「6층 601호로」

### S9. 강의실 세팅 ⏱ 1분
- 📷 빈 강의실 와이드 → HDMI 연결 → 빔에 PPT 뜨는 순간
- 📷 폰 화면을 노트북에 띄우기 (스마트뷰 → 무선 디스플레이)
- 🎤 (잘 되면) "됐다!" / (안 되면) "역시 한 번에 안 되죠. 이럴 땐 이렇게…" ← 이 장면 살리기
- 🔤 「세팅 꿀팁: 폰 화면 빔에 띄우기」 「강의까지 D-15분」

### S10. 강의 하이라이트 (뒤쪽 삼각대 고정) ⏱ 4~5분
- 📷 강사 + 화면만, **교육생 얼굴 ✕** (뒷모습·손은 괜찮음)
- 꼭 찍을 4장면
  1. **BLACK 공개** — "그 최고 등급 BLACK, 오늘 이 자리에 서 있습니다" → 반응 소리
  2. **세종대왕 사진** — 책 읽는 사진 → 노트북으로 바꾸는 순간 → 웃음 소리
  3. **Flow 영상** — 학자들 사진이 움직이는 영상 → "와~"
  4. **HTML 도구 시연** — 엑셀 넣자마자 그래프 나오는 순간
- 🔤 장면 제목 자막 + 반응 순간 「(웃음)」 「(박수)」

### S11. 쉬는 시간 ⏱ 30초
- 📷 단톡방에 올라오는 교육생 결과물 화면 녹화 (편집 때 이름·프로필 가리기)
- 🎤 (작게) "벌써 영상 올리신 분 계시네요."
- 🔤 「쉬는 시간에도 실습 중」

### S12. 강의 끝 ⏱ 40초
- 📷 마지막 장 「다음은 여러분입니다」 → 박수 소리 → 빈 강의실 → 노트북 덮기
- 📷 복도나 계단에서 소감 셀카
  - 🎤 "끝났습니다. 제일 반응 좋았던 건 세종대왕이었어요. 역시 웃겨야 기억에 남나 봐요."
  - 🎤 "선배님들이 내일 하나라도 써 보시면 성공입니다."
- 🔤 「강의 전 나 vs 강의 후 나」 (S1 셀카와 나란히)

### S13. 보너스 — 진주성·남강 (시간 되면) ⏱ 20초
- 📷 촉석루 · 남강 다리 15초, 산책하며 걷기
- 🎤 "출장의 맛은 이거죠."
- 🔤 「출장 보너스: 진주성」

### S14. 귀가 — 진주 → 마산 ⏱ 30초
- 📷 노을 타임랩스 (거치대) · 고속도로 야경
- 📷 정차 후 한마디: "다음 강의는 ○○입니다. 그것도 찍어 올릴게요."
- 🔤 「진주 → 마산」 「다음 편 예고」

### S15. 엔딩 (집) ⏱ 20초
- 📷 책상에서 노트북 열고 단톡방 확인 → 미소
- 🎤 "오늘 하루 같이 와 주셔서 감사합니다. AI, 일단 써 보세요."
- 🔤 「다음은 여러분입니다」 → 채널 아웃트로 영상

## 편집 장치
- **카운트다운 자막:** 「강의까지 D-3시간 → D-1시간 → D-15분」
- **체크리스트 연출:** 짐 쌀 때 ✔ 하나씩
- **반전:** 세팅이 안 돼 당황 → 해결 → 강의 성공
- **지역색:** 진주 음식, 남강, 진주성
- **배경음악:** 이동 장면은 경쾌하게, 강의 장면은 잔잔하게, 소감은 음악 줄이기

## 전날 체크리스트
- [ ] 인재개발원 담당자에게 촬영 미리 알리기 (강사 뒤에서 화면 위주, 교육생 얼굴 노출 없음)
- [ ] 폰 저장 공간 30GB 이상 비우기
- [ ] 보조배터리 완충 + 차량 충전기
- [ ] 거치대 · 삼각대 · (있으면) 핀마이크
- [ ] 노트북 화면 녹화 프로그램 확인 (PPT 화면 따로 녹화용)
- [ ] 신분증 (방문증 받을 때)

- 교육생 얼굴 · 이름표 · 출석부
- 단톡방 참여자 이름·프로필 (편집 때 가리기)
- 방문증 번호, 업무 서류
- 운전 중 폰 조작 (녹화는 출발 전에 켜기)
