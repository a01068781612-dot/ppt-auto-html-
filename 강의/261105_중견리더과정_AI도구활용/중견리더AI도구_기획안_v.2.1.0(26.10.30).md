## 1. 바뀐 방향

| 강사 요청 | 반영 |
|---|---|
| 실습 몇 개 + 동영상 | 블록마다 **1~2분 소개 영상 → 실습**. 말로 하는 설명은 블록당 1~2분 |
| 무료 · 폰 | 모든 실습을 **무료 계정 + 폰**으로. 무료 한도가 넉넉한 Gemini 중심 |
| Gemini 기본 앱 | 사진 만들기 · 사진 편집(배경 바꾸기) · 사진 읽기 · 유튜브 요약 · 캔버스 — 무료 · 앱 하나로 |

## 4. 블록별 진행

### 오프닝 — 단톡방부터
1. 표지 → 국무회의 인트로 영상 (♻️)
2. **“폰을 꺼내 주세요” → 오픈채팅 입장 QR** (오픈프로필로 입장 — 전화번호 안 보임)
3. 단톡방 공지에 미리 올려 둔 것: Gemini·Flow 링크, 실습 카드 PDF, 강의 순서
4. **카톡 투표**: AI 얼마나 써 보셨나요? (안 써 봤다 / 몇 번 / 매주 / 업무에도) → 카톡 PC 화면으로 결과
5. 강사 소개 (♻️, 짧게)

### 블록 1. 사진을 만든다 — 미션 1 ⭐
- 🎬 Gemini 사진 만들기·편집 소개 영상 (후보 찾아 확인받기)
- 강사가 먼저: 글로 “23기 중견리더 수료 축하 포스터, 진주성 야경 배경” → 이어서 강사 셀카 “배경을 스페인 해변으로”
- 따라 하기: ① **글로 새 사진 하나** ② **셀카(또는 옆 사람) 배경 바꾸기** → 마음에 드는 것을 **단톡방에 올리기** (원하는 분만)
- **사진 전시회**: 강사 노트북 카카오톡 PC를 빔프로젝터에 → 올라오는 사진을 같이 보며 소개
- 보너스: 흑백 가족사진 컬러 복원 · 캐리커처 · 증명사진
- **중요**: 미션 2에서 쓸 수 있게 **결과 사진을 폰에 저장**해 두기

### 블록 2. 그 사진이 영상이 된다 — 미션 2 ⭐
- 🎬 Flow 소개 영상
- 강사가 먼저: 미션 1 강사 사진을 Flow에 넣고 “사람이 천천히 웃으며 손을 흔들게” → 8초 영상 → 단톡방에 공개
- 따라 하기: 단톡방 공지의 **Flow 링크** → 구글 로그인 → **사진 올리기(시작 장면)** → 움직임을 말로 → 생성 기다리는 1~2분 동안 다음 설명
- 완성되면 **단톡방에 올리기 → 영상 전시회**
- **예비 경로**(Flow가 안 되는 분): 구글 포토 앱 → 「만들기」 → **「사진을 동영상으로」** (짧고 소리 없음)
- 무료 크레딧은 하루 빠른 영상 2편 정도 → **한 사람 1~2편**으로 안내

### 블록 3. 종이가 표가 된다 — 미션 3
- 따라 하기: Gemini에 **실습 카드 뒷면 표 사진** → “엑셀 표로 만들어 줘” · “민원 많은 3가지 요약해 줘”
- 쉬는 시간 전 3분: 강사가 **Claude 페이지**(교육생이 고른 주제)와 **「작업」 모드 일**을 걸어 두고 쉬는 시간

### 블록 4. AI에게 맡긴다 (강사 시연)
- Gemini **「작업」 모드**: AI가 웹사이트를 직접 누르는 진행 화면을 띄워 중계 (코레일 열차 조회 → 안 되면 경남도청 보도자료 요약) — **채팅과 같은 문장으로 비교**
- 성공 장면은 리허설 때 **폰 화면 녹화**해 두고 실패 시 영상으로 대체
- Claude로 만든 페이지: 게시 → QR → 모두의 폰에서 열기 → “색 바꿔 줘” 한 번 더
- (「작업」 모드는 유료라 교육생은 보기만)

### 블록 5. AI는 이제 일을 한다
- 🎬 AI 에이전트란 (♻️ 코딩알려주는누나 0:12~2:48) → 정리 ① (♻️)
- 🎬 프롬프트 시대는 끝났다 (♻️ 알렉스 0:00~1:57) → 정리 (♻️) — 시간 넘치면 생략
- 한 줄: “방금 쉬는 시간에 AI가 영상과 페이지를 만들었습니다 — 이게 일하는 AI입니다”

### 블록 6. 그래도 확인은 사람이 — 미션 5
- **AI가 틀린 곳 찾기** (세종대왕 맥북 · 경남 인구/도청 · 가짜 판례) → 정답
- **보안 3원칙** + 카톡 O/X 투표 4문항
- (선택) 리더십 영상 ♻️

### 마무리
- 카톡 다시 투표 → 처음 투표와 비교
- **단톡방에 “내일 출근해서 해 볼 것 하나”** 한 줄씩 → 화면에서 몇 개 읽기
- “일단 써 보세요. 작은 것부터.” → 강사 홍보 영상 → Q&A
- 단톡방 안내: 강의안 PDF 공지 · **1주일 뒤 방 정리**

| 투표 | 카톡 투표(＋ 메뉴 → 투표) 미리 만들어 두기: 설문 · O/X 4 · 다시 투표 — **오픈채팅에서 투표 메뉴가 되는지 사전 확인**. 안 되면 만들어 둔 투표 플랫폼(Apps Script) 사용 |
| 화면 | 강사 노트북 **카카오톡 PC** 로그인 → 빔프로젝터로 사진 전시회 · 투표 결과 |
| 주의 | 사진 올리기는 원하는 분만(얼굴) · 업무 자료·개인정보 올리지 않기 · 강의 끝에 **1주일 뒤 방 정리** 안내 |
