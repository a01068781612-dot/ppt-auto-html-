## 1. 설치 (한 번만, 약 5분)

1. **script.google.com** 접속 → 구글 로그인 → 왼쪽 위 **「새 프로젝트」**
2. 제목 「제목 없는 프로젝트」를 눌러 **`AI특강 투표`** 로 바꾸기
3. 편집기에 있는 `Code.gs` 내용을 **모두 지우고**, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣기
4. 왼쪽 「파일」 옆 **＋ → HTML** → 이름 **`vote`** (확장자 없이) → 안의 내용을 지우고 `vote.html` 내용 붙여 넣기
   같은 방법으로 **`screen`** 파일을 만들고 `screen.html` 내용 붙여 넣기 → **저장(Ctrl+S)**
5. 오른쪽 위 **「배포」 → 「새 배포」** → 톱니바퀴에서 **「웹 앱」** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **「배포」** → 「액세스 승인」 → 내 계정 선택 → *“Google에서 확인하지 않은 앱”* 화면이 나오면 **「고급」 → 「AI특강 투표(으)로 이동」 → 「허용」** (내가 만든 스크립트라 괜찮습니다)
   - 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/……/exec`)을 복사

> ✅ **이 URL을 Claude에게 보내 주세요.** PPT의 투표 QR 4곳(4·46·49·51장)에 실제 QR을 넣고, QR을 누르면 강사 화면이 열리게 링크도 걸어서 다시 만들어 드립니다.

## 2. 시험해 보기 (설치 직후)

| 누가 | 주소 | 확인할 것 |
|---|---|---|
| 강사 노트북 | 웹 앱 URL 뒤에 **`?v=screen`** | 비밀번호 **`1105`** 입력 → 대기 화면에 큰 QR |
| 내 폰 | 웹 앱 URL (또는 화면 QR 찍기) | "강의 화면을 봐 주세요" |
| 강사 노트북 | **→ 키** | 폰에 첫 문제가 3초 안에 뜸 → 폰에서 누르면 막대가 올라감 |

- 리허설 뒤에는 편집기 위쪽 함수 목록에서 **`전체초기화`** 를 골라 **「실행」** → 투표 기록이 모두 지워집니다.
- 비밀번호를 바꾸려면 `Code.gs` 맨 위 `ADMIN_PIN` 수정 → 저장 → 아래 3번처럼 새 버전 배포.

## 3. 고친 뒤 다시 배포 (주소는 그대로)

`Code.gs`·HTML을 고쳤으면 **「배포」 → 「배포 관리」 → 연필(편집) → 버전: 「새 버전」 → 「배포」**.
「새 배포」를 누르면 **주소가 바뀌어 PPT QR이 안 맞으니** 꼭 「배포 관리」로 하세요.

## 4. 사진 퀴즈 정답 넣기

사진 5장을 정한 뒤 `Code.gs`의 `p1`~`p5` 줄에서 `answer: null` 을 바꿉니다.
- AI가 만든 사진이면 **`answer: 0`**, 진짜 사진이면 **`answer: 1`**
- 예: `{ id: 'p1', … options: ['AI다', '진짜다'], answer: 1 },`
- 정답을 넣어야 강사 화면에서 **R(정답 공개)** 이 작동하고, 교육생 폰에 "🎉 정답입니다!"가 뜹니다. → 3번처럼 새 버전 배포

## 5. 당일 운영

**준비**: 노트북에 PPT(슬라이드 쇼)와 크롬 창(강사 화면 `?v=screen`)을 함께 띄워 두고 **Alt+Tab**으로 오갑니다.

| PPT 장 | 강사 화면에서 | 교육생 |
|---|---|---|
| 4 설문 QR | → 로 「AI, 얼마나 써 보셨나요?」 | QR 찍고 투표 → 강사 화면으로 전환해 결과 보여 주기 |
| 6~10 사진 Q1~Q5 | → 로 「1번 사진은?」… 투표 뒤 **R** 정답 공개 | 사진마다 AI다/진짜다 |
| 46 O/X | → 로 O/X 1~4번 차례로, 각각 **R** | O/X 고르기 |
| 49 다시 투표 | → 로 「처음과 지금」 — **처음 결과와 나란히** 표시 | 투표 |
| 51 한 줄 약속 | → 로 「내일 해 볼 것 하나」 — 적은 글이 화면에 모임 | 한 줄 쓰고 보내기 |
| 그 밖 | **0** 대기 화면 (큰 QR) | "강의 화면을 봐 주세요" |

**강사 화면 단축키**: `→`/`←` 다음·이전 문제 · `R` 정답 공개/숨기기 · `Q` QR 크게 · `0` 대기 화면 · `C` 아래 조작 막대 고정 (마우스를 화면 아래로 가져가도 나타남)

## 6. 알아 둘 것

- 교육생 폰은 3초마다 강사 화면의 현재 문제를 따라갑니다. 같은 문제에서 다시 누르면 **답이 바뀝니다**(한 사람 한 표).
- 페이지 위에 *"Google이 아닌 사용자가 만든 애플리케이션"* 이라는 회색 띠가 보일 수 있습니다 — 개인 계정 Apps Script의 정상 표시입니다.
- 40~50명이 동시에 눌러도 됩니다. 와이파이가 느리면 **LTE로 접속**하도록 안내하세요.
- 투표 기록은 내 구글 계정의 스크립트 안에만 저장되고, 이름 등 개인정보는 받지 않습니다.

## 7. PART 3 라이브 제작 — 만든 결과를 폰으로 보내는 방법

1. Claude(claude.ai)에 주문 → 결과 화면(아티팩트) 오른쪽 위 **「게시(Publish)」** → **링크 복사**
2. 크롬 새 탭에 링크 붙여 넣기 → 주소창 오른쪽 **공유 아이콘 → 「QR 코드 만들기」** → 화면에 띄우기
3. 교육생이 QR을 찍으면 폰에서 바로 열림

- **리허설 때 꼭 한 번** 해 보세요 (로그인 안 한 폰에서 열리는지 확인).
- 안 되면 대안: 결과를 HTML 파일로 내려받아 **app.netlify.com/drop** 에 끌어다 놓기 → 바로 주소가 생김 → 2번과 같이 QR.
- 실패 대비 완성본(수료식 초대장·버킷리스트·룰렛)은 노트북에 미리 만들어 두고 같은 방법으로 공유합니다.
