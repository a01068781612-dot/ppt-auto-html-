## 4. 화면 문구 (확정)

## 5. 제작 방법 (새 방에서 다시 만들 때)
| 단계 | 파일 | 비고 |
|---|---|---|
| 정리 10장 생성 | `gen1020.py` | 원본 `scratchpad/hf/st/gen.py`를 잘라 SUMS만 교체한 것 (경로 의존) |
| 강사 소개 1·2 생성 | `prof1020.py` | 웹 프로필 반영본 |
| 모션 HTML 원본 | `motion_html/{st,news,art,op2}/*/index.html` | **텍스트만** 저장. 기사 캡처(cap.jpg)·사진·사진 배경(bg.png)·gsap·글꼴은 저작권/용량 때문에 git에 없음 |
| 사각 장식 | `motion_html/sqfix.py` | HTML 생성 후 반드시 다시 실행 |
| 렌더 | `render.sh` + `rl.txt` | HyperFrames 0.8.126, `--crf 24` |
| PPT 조립 | `build1020.js` → `timing.py` | 영상·모션 mp4 경로(`/tmp/vids/m1020/`, `/tmp/vids/clips/`)는 원래 방 컨테이너에만 있음 |

**주의 — 미디어는 원래 방 컨테이너에만 있다.** 새 방에서 장면을 다시 렌더하려면 이미지·영상이 필요하다. 방법:
1. 강사가 최종 PPT(v.1.0.2)를 올려 주면 `ppt/media/`에서 모션·영상·사진을 모두 꺼내 쓸 수 있다(pptx는 zip). 단, 대화 업로드는 30MB 제한이 있으니 조각(`w1020v102.part01~11`)으로 올리고 `cat`으로 합친다.
2. 글자만 바꾸는 수정이면, 해당 장면 HTML(`motion_html`)을 고치고 필요한 이미지만 PPT에서 꺼내 렌더한다.
3. 큰 재렌더가 필요하면 원래 방에서 해도 된다(원래 방에는 모든 원본이 남아 있음 — 컨테이너가 살아 있는 동안).
