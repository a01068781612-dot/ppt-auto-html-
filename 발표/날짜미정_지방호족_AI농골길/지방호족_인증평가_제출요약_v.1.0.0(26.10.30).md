## 한 줄

## 축 1. AI 문제해결 사례 (119 스마트 진입로 판정)
```
[문제] 2024.8 농촌 골목 화재 사망
  → 진입 가능 여부 = 대원 기억뿐 / 내비 = 승용차 기준
  → 기존 해법: 140명 · 1년 · 239개 마을 실측 → 책자(글뿐)
  → 한계: 18개 소방서 반복 · 지도·호스 정보 없음
        ↓
[해결] 공공 지도(VWorld 지적도·위성사진) + AI
  → ① 도로 폭 ② 코너 통과(차폭 2.5m · 코너 3.62m) ③ 차량 진입 경로
    ④ 하차 지점·호스 본수(15m) ⑤ 내비 길안내 연동
  → 결과: 마을 이름 입력 → 1초 → 지도에 색(가능·주의·불가)
        ↓
[검증] 정답지 = 현장 실측 책자(검증 전용, 판정 투입 0)
  → 일치율 69.55% → 84.04%
  → 원인: 집 없는 논둑길 오판정 → 주거지 필터로 해결
        ↓
[한계·보호] 84% → 나머지 사람 확인 / 출동 참고 정보(지휘관 판단 우선) / 실명 가림본
```

## 축 2. 6개월 성장
```
[4~7월 교육]   바이브 코딩 첫 실습 · 슈파베이스 · API 첫 연결
      ↓
[8~9월 개인]   홍보 영상 자동화 도구
               내용 입력 → 대본(클로드 소넷) → 이미지(GPT 이미지·나노바나나)
               → 영상(Veo·시댄스) → 음성(구글 TTS) → 완성 영상
      ↓
[9월 말~10월 팀] 119 스마트 진입로 판정 · 4개 기관 4명 · 5주 · 168시간 · 일치율 84%
      ↓
[공유]         상황관리 워크숍(105명) · 광주소방학교 특강
```
- 전후 비교: 경험 없음 → 직접 제작 / 개념만 → 연결·활용 / 수작업 영상 → 자동 완성 / 감 → 숫자
- 본인 기여: 문제 제기 · 실측 자료 · 판정 프로그램 제작·개선 · 발표 자료·영상
- 성장: 문제 쪼개기 / 부족: 정확도, 제도 정착

## 예상 질문 → 답변 핵심
| 질문 | 답변 핵심 |
|---|---|
| 왜 84%에 그쳤나 | 위성사진의 나무 그림자·처마로 폭 오판. 그래서 **AI 1차 판정 + 사람 확인** 구조 |
| 나머지 16%는 위험하지 않나 | 출동 참고 정보, 최종 판단 = 현장 지휘관. 의심 구간은 사람이 현장 확인 |
| 내비와 차이 | 내비 = 승용차 길. 우리 = 소방차 폭·코너·하차 지점·호스 본수 |
| 본인 역할 | 문제 제기, 실측 자료, 판정 프로그램 제작·정확도 개선, 발표 자료 |
| 6.6억 절감 근거 | 인원·시간·시간당 단가는 **가정**, 18개 서는 의령 규모 단순 환산이라고 먼저 밝힘 |
| 정답지를 학습에 썼나 | 아니오. 검증에만 사용(정답 유입 0) → 책자 없는 다른 소방서에도 적용 가능 |
| 개인정보 | 실명 가림본만, 공공 지도·위성사진만 사용 |
| 바이브 코딩으로 뭘 했나 | 슈파베이스 저장, API 연결 → 영상 자동화 도구 · 진입로 판정 프로그램 |
| 영상 자동화 실제 효과 | 담당자 촬영·편집 없이 내용 입력만으로 완성 (사용 기관·건수는 본인 기억으로) |
| 첫 3개월 계획 | 11월 보고·시범 서 2곳 → 12월 시범 판정·현장 확인 → 1월 결과 보고·18개 서 교육 |
