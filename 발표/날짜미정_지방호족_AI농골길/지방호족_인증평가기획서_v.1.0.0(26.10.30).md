## 1. 추진 배경 — 질문 하나

> **"이 골목, 소방차가 들어갈 수 있습니까?"**

- **2024년 8월**, 이 질문에 답하지 못한 농촌 골목에서 화재로 한 분이 돌아가셨다. 진입 가능 여부는 **가 본 대원의 기억**에만 있었고, 처음 가는 대원은 승용차 기준 내비게이션을 믿고 들어갔다.
- 일반 내비게이션(T맵·네이버·카카오)은 **승용차의 답**이다. 소방차는 차폭 2.5m, 길이 6.8~8.5m라 직선 폭이 맞아도 **90° 코너에서 끼여** 오도 가도 못 한다.

### 첫 번째 답 — 사람이 만든 답 (성과와 한계)

| 단계 | 내용 | 성과 |
|---|---|---|
| 현장 조사 → 책자 | 의령소방서 **140명이 1년** 동안 239개 마을을 직접 가서 폭을 쟀다 | 현장 대응 7~8분 → 4~5분, **약 3분 단축** · 도지사상 |
| 책자 → GPTs | 출동 중 책을 찾기 느려 GPTs(AI 농골길 코치)로 만들었다 | 마을 판단 90초 → 25초, **65초 단축** · 소방청장상 |
| 확산 | 경남 18개 소방서 시행 (재난대응과-5976, 2026.5.14.) | — |

### 남은 문제 두 가지

| # | 페인 포인트 | 규모 |
|---|---|---|
| ① | **답을 만드는 데 1년** — 사람이 직접 가야 하고, 18개 소방서가 같은 일을 또 해야 한다 | 의령 1곳 66,000 인·시간 × 18 |
| ② | **받은 답이 글뿐** — 지도도, 경로도, 내려서 호스를 몇 본 들고 어디로 뛰어야 하는지도 없다 | 출동 중 글을 읽어야 함 |

## 2. 해결 방안 — 사람 대신 지도에게 묻는다

### 차별성: 글을 읽는 AI(T2T)가 아니라, 지도를 보고(I2T) 지도로 답하는 AI(T2I)

| 구분 | 기존(책자 · GPTs) | 119 스마트 진입로 판정 |
|---|---|---|
| 입력 | 사람이 잰 실측값 · 글 | VWorld 연속지적도 · 위성사진 (공공 데이터) |
| 처리 | 사람이 판단 | 도로 폭 자동 산출 + 차체 회전 궤적 계산 |
| 출력 | 글 설명 | **지도 위에 색으로 그린 경로** (진입 가능 · 주의 · 불가) |
| 새 마을 | 다시 현장 조사 1년 | **마을 이름 입력 → 1초** |

### 판정 방식

1. **도로 폭 산출** — 도로 중심선에서 1m 간격으로 수직선을 내려 좌·우 경계(담장·건물)까지 거리를 잰다. 위성사진 딥러닝 분할(Mask2Former)로 처마·창고 돌출을 보정한다.
2. **소방차 기준 판정** — 중형펌프차 차폭 **2.5m**, 90° 코너는 내륜차·외륜차를 더한 **3.62m** 이상이어야 통과로 본다.
3. **1차 차량 진입 경로** — 소방차가 안전하게 갈 수 있는 마지막 지점(하차 거점)까지 경로를 그린다.
4. **2차 호스 연장 경로** — 하차 거점에서 화점까지 골목 도보 거리와 **15m 호스 몇 본**이 필요한지 계산한다.
5. **현장 연동** — 안전 우회 경유지를 넣어 T맵·네이버·카카오 길안내를 한 번에 호출하고, 건축물대장을 실시간 조회한다.

### 5주 동안 고친 것 — 정확도를 올린 3대 개선

| 개선 | 무엇을 바꿨나 | 효과 |
|---|---|---|
| ① 주거 코어 필터링 | 집이 없는 논두렁길·산길을 골목 판정에서 분리 | 가짜 위험 경보(오탐) **20,376건 → 8,940건 (−56.1%)** |
| ② 2D 차체 스윕폭 · 편측 담장 보정 | 굽은 골목에서 차체가 쓸고 가는 면적 계산 | 실제 병목 적중 **+42.2%** |
| ③ 다중 입구 · 골목 흐름 스무딩 | 나무 그림자 한 곳 때문에 골목 전체가 막히는 오류 제거 | 판정 안정화 |

## 3. 검증 결과 — 사람이 1년 그린 선과 AI 선을 겹쳐 봤다

| 지표 | 개선 전 | 개선 후 |
|---|---|---|
| 구간 판정 정확도 | 69.55% | **84.04% (+14.48%p)** |
| F1-Score | 16.28% | **34.54% (2.12배)** |
| 오탐(외곽 농로 오차단) | 20,376건 | **8,940건** |
| 범위 | — | 13개 읍·면 · 239개 마을 · 89,681개 구간 |
| 정답 데이터 유입 | — | **0건** (공공 API + 위성 AI + 물리·기하 규칙만 사용) |

- 정답지(현장 실측 책자)는 **검증에만** 쓰고, 판정에는 넣지 않았다 → 책자가 없는 다른 17개 소방서에도 그대로 쓸 수 있다.
- AI가 84%를 먼저 판정하고, 사람은 나머지 의심 구간만 확인하는 **AI 1차 판정 + 사람 확인** 구조다.

## 4. 기대효과 (정량)

표시: 실측 = 기록된 값 · 가정 = 확인이 필요한 값 · 목표 = 이번 과제로 기대하는 값

### ① 인력 — 사람이 가야 하는 시간

| 항목 | 의령 1곳 | 경남 18개 소방서 |
|---|---|---|
| 지금 (사람이 전부 조사) | 66,000 인·시간 | 1,188,000 인·시간 |
| 이번 과제 (우리 팀 실제 투입) | 168 인·시간 | — |
| **아끼는 시간** | **65,832시간** | **약 118만 시간** (1,184,976) |

가정: 일근 40명 × 250일 × 3시간 + 교대 100명 × 120일 × 3시간 = 66,000 인·시간. 우리 팀 = 서울 모임 4회 × 8시간 + 온라인 주 1회 × 2시간 × 5주, 4명 = 168시간. 18개 소방서는 의령 규모로 단순 환산.

### ② 예산

| 항목 | 의령 1곳 | 경남 18개 소방서 |
|---|---|---|
| 지금 | 인건비 6억 6,000만 + 책자 515만 = **6억 6,515만 원** | 약 119억 7,270만 원 |
| 이번 과제 | 168시간 × 2만 원 + AI 구독료 30만 원 = **366만 원** | — |
| **아끼는 예산** | **6억 6,149만 원** | **약 119억 원** (119억 682만) |

가정: 현장 조사 시간당 1만 원, 우리 팀 인건비는 보수적으로 시간당 2만 원.

### ③ 골든타임

| 단계 | 줄어든 것 | 값 | 근거 |
|---|---|---|---|
| 책자 | 현장 대응 7~8분 → 4~5분 | 약 3분 단축 | 실측(언론 보도) |
| GPTs | 출동 중 마을 판단 90초 → 25초 | 65초 단축 | 실측(대원) |
| 이번 과제 ① | 글을 읽지 않고 지도로 바로 판단 | 25초 → **10초 이내** | 목표 |
| 이번 과제 ② | 하차 거점·호스 본수를 출동 전에 앎 | 최심부 호스 전개 2분 6초 → **1분 이내** | 9월 훈련 9개 마을 평균(실측) · 목표 |
| 이번 과제 ③ | 코너 끼임 구간을 미리 빨강·주황 표시 | 막다른 골목 진입·후진 **0회** | 목표 |
| **합계** | ① + ② | **약 1분 20초 추가 확보** | 목표 |

## 6. 맺음 — 이제는 답할 수 있다

- 1년 → 90초 → 25초 → **1초**. 같은 질문에 답이 나오는 시간이 이렇게 줄었다.
