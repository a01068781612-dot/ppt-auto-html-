## 1. 6개월 성장 타임라인

```text
[1~2개월차 · 교육] 【확인: 수강 과목명】 과정에서 생성형 AI 활용, 데이터 분석, 바이브 코딩(AI에게 말로 지시해 프로그램 만들기)을 배웠다. 배운 점은 "AI는 답을 주는 도구가 아니라 일을 맡기는 동료"라는 것. 이후 GPTs로 만든 'AI 농골길 코치'(239개 마을 정보 검색)를 출동 현장에서 다시 점검해, 마을 판단 시간을 90초에서 25초로 줄였다.

[3~4개월차 · 특강·대외 활동] 【확인: 시기】 행정안전부 AI 챔피언 최고등급(BLACK)을 받고, 국가인재개발원 AI 활용 e러닝 강사, 경상남도 AI 활용 대표 내부강사로 활동했다. 국토교통부 등 27개 기관에 출강·자문했다. 【확인: 실제로 받은 피드백】 수강생 반응을 반영해, 외부 사례 대신 공공 문서 양식과 내부 보안 환경을 그대로 쓰는 실습형으로 강의를 바꿨다.

[5개월차 · 개인 프로젝트] AI 재난 원패스(행정안전부 장관상, 대상), 119원패스 AI 플랫폼 연구(도지사 표창) 등을 추진했다. 【확인: 과정의 개인 프로젝트로 낸 과제명】 적극행정 심사 기준("기존 수상 사례 단순 수정은 제외")을 반영해, 수상 후 새로 생긴 성과(소방청 전국 확산 공문, 내비 연계 차량 497대)를 숫자로 분리해 정리했다.

[6개월차 · 팀 프로젝트] 4개 기관(인사혁신처·경찰·소방·해양경찰) 4명이 5주간 '119 스마트 진입로 판정'을 만들었다. 처음 판정 정확도가 69.55%에 그쳐 원인을 분석한 결과, 집이 없는 논두렁길까지 위험으로 판정하는 오탐이 많다는 것을 알았다. 이를 바로잡아 84.04%까지 올렸다. 기대효과도 과장하지 않도록 우리 팀이 실제로 쓴 시간(168시간) 기준으로 다시 계산했다.

[과정 후] 10.08 경남소방본부 구조구급 AI 특강, 10.20 상황관리 공감 워크숍(105명), 10.23 광주소방학교 직장훈련 우수사례 특강, 11.05 경남인재개발원 중견리더과정 AI 강의(예정)로 배운 내용을 조직에 나누고 있다.
```

## 2. 과정 전후 역량 비교

```text
[과정 전 → 지금 할 수 있는 일 (산출물 기준)]

1. 정보 정리 → 데이터 판정
 - 전: 140명이 1년간 현장에서 잰 결과를 책자(글)로 정리하는 수준
 - 지금: VWorld 지적도·위성사진만으로 239개 마을, 89,681개 도로 구간의 소방차 진입 가능 여부를 1초 만에 판정하는 웹앱 (정확도 84.04%)

2. AI 사용자 → AI로 만드는 사람
 - 전: 챗GPT에 질문하고, GPTs에 자료를 넣어 검색하는 수준 (글로 답함)
 - 지금: 바이브 코딩으로 공공 API(VWorld·건축물대장)를 연동하고, 판정 결과를 지도에 그리며, T맵·네이버·카카오 길안내까지 바로 호출하는 프로그램 구현

3. 감으로 하는 설명 → 숫자로 하는 검증
 - 전: "빨라졌다"는 정성 표현
 - 지금: 정답지(현장 실측 책자)와 겹쳐 정확도·F1(16.28%→34.54%)·오탐 수(20,376→8,940건)로 검증하고, 실측·가정·목표를 구분해 기대효과를 제시

4. 혼자 하는 일 → 다기관 협업
 - 전: 소방 내부 업무
 - 지금: 4개 기관 팀에서 문제 정의부터 발표까지 이끌고, 105명 규모 워크숍 강의 진행

[팀 결과물 중 본인 기여]
 - 본인(김경훈, 소방): 현장 문제 정의(2024.8 사고, 농골길 사업), 정답지·현장 자료 제공, 판정 엔진·웹앱 개발과 정확도 개선, 검증, 발표 자료·영상 제작 【확인: 실제 분담에 맞게 수정】
 - 팀원: 【확인: 홍준표·유도암·이은주 각자 맡은 일 — 예) 기대효과 산정, 타 기관 적용성 검토, 발표·시나리오】
```

## 3. 자기 진단과 후속 학습

```text
[가장 성장한 점] 문제를 "AI에게 맡길 수 있는 단위"로 쪼개는 능력이다.
사례: 팀 프로젝트에서 "소방차가 들어갈 수 있나"라는 막연한 질문을 ① 도로 폭 산출 ② 90° 코너 회전 계산(3.62m) ③ 하차 거점·호스 본수 계산으로 나눴다. 그 덕분에 정확도가 낮을 때도 어느 단계가 틀렸는지 찾을 수 있었고, 69.55%에서 84.04%로 올렸다.

[아직 부족한 점 1] 모델 성능을 끝까지 끌어올리는 기술 깊이.
사례: 정확도 84%, F1 34.54%는 아직 현장에서 "사람 확인 없이" 쓸 수준이 아니다. 오탐을 줄이는 것은 규칙으로 해결했지만, 위성사진 분할 모델을 직접 개선하는 것은 아직 어렵다.
→ 학습: 빅데이터분석기사·ADsP 기반 위에, 【확인: 수강 중인 강좌】로 영상 분할·모델 평가를 공부 중. 다음 행동: 현장 확인 결과를 정답 데이터로 모아 재학습해 F1 50% 이상을 목표로 한다.

[아직 부족한 점 2] 만든 것을 조직 제도로 바꾸는 힘.
사례: GPTs와 판정 웹앱은 잘 쓰이지만, 담당자가 바뀌면 멈출 수 있다. 공문·예산·운영 책임자 없이 개인 역량에 기대고 있다.
→ 다음 행동: 경남 18개 소방서 농골길 사업(재난대응과-5976)에 공식 도구로 넣고, 서별 담당자용 사용 설명서와 점검표를 만든다.
```

## 4. 거점 리더 목표와 첫 3개월 계획

```text
[1년 목표] 경남 18개 소방서가 1년 걸리던 농촌마을 진입로 조사를 "AI 1차 판정 + 확인 조사"로 바꾸고, 소방서마다 AI 활용 담당자 1명 이상을 키운다.
 - 완료 확인: ① 18개 서 판정 지도 구축 수 ② 서별 확인 조사 시간(의령 기준 66,000 인·시간 대비) ③ 서별 AI 담당자 명단

[첫 3개월 계획]
1개월차(11월)
 - 대상: 119종합상황실, 재난대응과 농골길 담당
 - 활동: 판정 웹앱 시연·보고, 시범 소방서 2곳 선정 요청, 11.05 중견리더과정 강의에서 사례 공유
 - 필요 자원: 업무 보고 1건, VWorld API 키(무료)
 - 완료 확인: 시범 서 선정 공문 또는 보고서 결재

2개월차(12월)
 - 대상: 시범 소방서 2곳 담당자
 - 활동: 관할 마을 AI 1차 판정 → 현장 확인 조사(의심 구간만) → 틀린 구간 기록
 - 필요 자원: 담당자 서별 1명, 노트북·태블릿, 출장 1~2회
 - 완료 확인: 시범 서별 판정 지도, 현장 확인 결과표(정확도·소요 시간)

3개월차(1월)
 - 대상: 경남 18개 소방서, 소방본부
 - 활동: 시범 결과 보고, 확인 결과로 판정 기준 보정, 사용 설명서·점검표 배포, 담당자 교육 1회
 - 필요 자원: 교육 장소·시간 2시간, 결과 보고 공문
 - 완료 확인: 결과 보고서, 교육 참석자 명단, 18개 서 확산 계획 결재
```

## 5. 조직 설득·협업과 준비 상태

```text
[관리자·동료를 참여시킬 방법]
 - 관리자: "1년·6억 6천만 원 걸리던 일을 AI 1차 판정으로 줄인다"는 숫자와, 이미 시행 중인 농골길 사업(재난대응과-5976)에 얹는 방식으로 설명한다. 새 사업이 아니라 기존 사업의 비용을 줄이는 것이라 승인 부담이 적다.
 - 동료(현장 대원): 직접 써 보게 한다. 마을 이름을 넣으면 1초 만에 진입로와 호스 본수가 지도에 나오는 것을 훈련 때 보여 주고, 틀린 곳을 대원이 표시하면 반영한다.

[이미 한 일]
 - 의령군 239개 마을 판정 지도 구축과 정답지 검증(정확도 84.04%)
 - 선행 성과: 농골길 책자(현장 대응 약 3분 단축, 도지사상), AI 농골길 코치 GPTs(65초 단축, 소방청장상), 경남 18개 소방서 시행
 - 4개 기관 4명 팀으로 5주 168시간 협업
 - 확산 기반: 10.20 상황관리 워크숍(105명, 상황실·소방서), 10.23 광주소방학교 특강, 소방청 AI 인력풀 개발팀 합류

[필요한 승인]
 - 소방본부: 시범 소방서 지정, 농골길 사업에 AI 판정 도구 포함
 - 정보보안: 웹앱의 내부망·업무 PC 사용 검토, 공공 API 사용 확인

[예상 장애와 대응]
 - 정확도 불신 → "보조 정보 + 사람 확인" 원칙을 분명히 하고, 시범 결과를 숫자로 공개
 - 현장 업무 부담 → 의심 구간만 확인하도록 해 조사량을 줄임
 - 담당자 교체 시 중단 → 설명서·점검표, 서별 담당자 2명 지정
```

## 6. 책임 있는 AI 활용·공유·지속 실천

```text
[기관 AI 활용 기준을 지키는 방법]
 - 개인정보: 화재피해약자 실명 등은 가림본만 사용하고, 개인정보가 담긴 공문 원문은 외부 AI·저장소에 올리지 않는다.
 - 공공 데이터만 사용: VWorld·건축물대장 등 공공 API와 공개 위성사진만 쓰고, 정답지(현장 실측 책자)는 판정에 넣지 않고 검증에만 쓴다(정답 유입 0건).
 - 판정의 위상: AI 판정은 출동 보조 정보이며 현장 지휘관 판단을 대신하지 않는다고 화면과 설명서에 적는다.

[결과를 확인하는 방법]
 - 정답지와 구간별로 겹쳐 정확도·F1·오탐 수를 측정한다(현재 84.04%).
 - 현장 확인 결과를 기록해 틀린 구간을 다시 반영하고, 기준이나 데이터가 바뀔 때마다 같은 방법으로 다시 측정한다.
 - 기대효과는 실측·가정·목표를 구분해 표기하고, "사망자 감소" 같은 근거 없는 예측은 쓰지 않는다.

[동료와 나누는 활동]
 - 10.08 경남소방본부 구조구급 AI 특강, 10.20 상황관리 공감 워크숍(105명), 10.23 광주소방학교 직장훈련 우수사례 특강, 11.05 경남인재개발원 중견리더과정 AI 강의(예정)
 - 국가인재개발원 AI 활용 e러닝, 유튜브·인스타그램 'Inside AX', 웹 프로필(ssca1612.pages.dev)에 사례 공개
 - 강의 때마다 "보안 3원칙"【확인: 실습 카드 문구】(개인정보·내부 문서 입력 금지, 결과는 사람이 확인, 출처 확인)을 실습 카드로 나눈다.

[지속 실천 계획]
 - 분기 1회: 판정 정확도 재측정과 결과 공유(소방본부·시범 서)
 - 월 1회: 상황실 내 AI 활용 사례 공유 모임 【확인: 운영 여부】
 - 반기 1회: AI 활용 원칙 점검표로 개인정보·보안 준수 여부 자체 점검
 - 3단계 고도화: 현장 확인 결과 재학습, 음성 안내, 상황실 출동 지령 연동
```
