## 대사 ↔ 화면
| 대사 | 화면(영상 시간) |
|---|---|
| 출동 중 차 안에서, 마을 이름만 넣습니다 | 입력창에 "박진마을" 입력 (0~3초) |
| 박진마을. 최심부 진입 불가, 호스 다섯 매, 소화전 있음 | 답 표: 최심부 진입 가능 여부 ✕ 불가 · 필요 소방호스 약 5매 · 마을 내 소화전 있음 (3~9초) |
| 이십오 초면 나옵니다 | 진입 · 소방 접근 표로 내려감 (9~12초) |
| 차량 배치와 전술까지 알려 줍니다 | 출동 전술 시뮬레이션 · 1단계 차량 배치 (12~17초) |
| 하지만, 전부 글입니다 | 글이 계속 내려감 → 끝 (17~20초) |

- 녹음 길이에 맞춰 영상 속도를 조정함(20초를 넘어도 됨)
- "이십오 초" = 대원 실측(90초 → 25초)
