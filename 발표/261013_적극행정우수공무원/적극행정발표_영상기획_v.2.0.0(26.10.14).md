## 🎬 영상1 — "골든타임은 세 번 늦어집니다" (45초)

**목표**: 심사위원이 숫자를 보기 전에 "아, 이건 진짜 문제다"를 몸으로 느끼게. 담담하고 무겁게.
**음악**: 낮은 드론(저음 지속음) + 심장박동처럼 느린 킥. 마지막에 뚝 끊김.

| 0:04–0:14 | **① 출동** 소방차 앞유리 시점: 막힌 도로, 늦게 비키는 차들 | **사이렌이 들릴 때, 이미 늦습니다** | 사이렌 + 경적 | 소방차 블랙박스 ★ |

## 🎬 영상2 — "지금, 실제로 작동합니다" (1분 20초)

**목표**: ①② 실제 화면으로 "말이 아니라 돌아간다"를 증명하고, ③은 설계임을 밝힌 뒤, 엔딩에서 가슴을 울린다.
**음악**: ①~③ 가볍고 또렷한 비트(화면이 주인공) → 엔딩에서 끊고 피아노 한 대.

| 시간 | 장면 | 자막 | 소리 | 소스 |
|---|---|---|---|---|
| 0:00–0:03 | 4p의 세 칸이 하나씩 켜짐(출동 → 대응 → 복구) | **지금, 실제로 작동합니다** | 비트 시작 | 모션 |
| **① 출동 — 실제** 0:03–0:23 | 운전자 시점 카카오내비 화면: 평소 안내 → **'띵' "긴급차량 263m 뒤 접근 중"** 빨간 알림 → 거리 77m로 줄어듦 → 차가 오른쪽으로 비켜 줌 → 소방차가 옆을 지나감 | 출동 — **사이렌보다 먼저, 내비가 알려 줍니다** / 하단 작게: 카카오내비 · 2026. 4. 20. 전국 최초 · 경남 497대 | 알림음 '띵' 강조 → 사이렌이 지나감 | ★★★ 내비 화면 녹화 (없으면 실제 캡처 3장으로 대체, 아래 B안) |
| **② 현장대응 — 실제** 0:23–0:43 | 농골길 GPTs 화면 녹화: 출동차 안 태블릿 → 마을 이름 입력("무곡마을") → **5초 안에** 진입로·불가 지점·소방호스 거리 답 표시 → 책자 지도와 같은 내용 | 현장대응 — **책 넘기던 90초가, 5초로** / 하단 작게: 예산 0원 · 직접 구축 · 출동→방수 7.5분 → 4.5분 | 타자 소리, 화면 오른쪽 위 초시계 0→5초 | ★★★ GPTs 화면 녹화 + 책자 p.220 위성지도 |
| **③ 복구 — 설계 시연** 0:43–1:00 | 원패스 앱 화면 모션: 재난 문자 수신 → "집이 불에 탔어요" 말로 접수 → 사진 1장 → AI 피해 정리 → 6개 기관 아이콘이 가운데로 모임 → **"신청이 완료되었습니다"** · 오른쪽 위 계속 **"설계 시연 화면"** 표기 | 복구 — **한 번의 신청으로, 6개 기관까지** / 하단 작게: 행정안전부장관상(대상) · 정부24 개발 착수 | 버튼 '톡' 소리, 완료 알림음 | 모션 제작(원패스 제안서 6~7쪽 앱 화면 기준) |

엔딩 문구 "이미 있던 것에, 한 층을 더했을 뿐입니다"는 4p 타이틀과 같은 말로 맞춤.

### ① 출동 화면이 녹화가 안 될 때 (B안)
실제 소방차가 지나가는 순간을 찍기 어렵다. 이때는:
- 실제 캡처 3장(263m → 77m → 해제)을 휴대폰 틀에 넣고 **화면 확대·이동 모션**으로 20초 구성
- 알림 박스에 빨간 테두리가 깜빡이고 거리 숫자가 263 → 77로 줄어드는 모션
- 자막 아래에 **"실제 서비스 화면"** 표기(재연 아님을 밝힘)

## 3. 화면 규칙
- 자막: Pretendard 굵게, 흰 글자 + 반투명 검정 띠, 한 줄 18자 안팎, 2.5초 이상 노출
- 실제 화면 장면에는 오른쪽 아래 작게 **"실제 서비스 화면"**, 원패스에는 **"설계 시연 화면"**
- 숫자는 PPT와 똑같이: 2.3배 · 164곳 · 90일 / 263m · 5초 · 7.5분→4.5분 / 6개 기관 · 14일→7분
- 90.3일은 출처 확정 전까지 영상에서는 **"90일"**로만

## 4. 넣는 법과 예비본
- PPT: 2·5번 슬라이드에 삽입 → 화면 전체 크기 → 재생 "자동 실행" + "전체 화면 재생"
- 파일이 크면(30MB↑) 720p로 줄인 버전 같이 준비
- 예비본: 영상 MP4 2개를 USB에 따로 + PPT 전체를 영상으로 저장한 MP4 1개
