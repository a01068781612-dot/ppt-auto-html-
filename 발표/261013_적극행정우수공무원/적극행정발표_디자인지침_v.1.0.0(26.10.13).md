## 1. 톤
- 흰 바탕 보고서형. 화려함보다 **신뢰·근거**. 한 장 = 한 메시지 + 근거(그래프·사진·증빙)
- 장 제목은 보고서 목차형: `Ⅰ. 추진 배경` `Ⅱ. 추진 내용` `Ⅲ. 주요 성과` `Ⅳ. 확산`
- 문장은 개조식(□ ○ -), 끝맺음 명사형("~ 구축", "~ 단축")

## 2. 색
| 이름 | 값 | 쓰임 |
|---|---|---|
| 바탕 | `#FFFFFF` / 구역 `#F4F6F9` | |

| 소방 적색(강조) | `#C8102E` | 핵심 숫자, 강조 막대, '전국 최초' 배지 |
| 글자 | `#1A1A1A` / 보조 `#4A4F57` / 캡션 `#7A808A` | |

| 회색 막대 | `#B8C0CC` | 비교 대상(전·기존) |

## 3. 글꼴·배치
- Pretendard. 제목 52px 800 / 핵심 숫자 72~120px 900 / 본문 26~30px 600 / 캡션·출처 18px
- 상단: 왼쪽 장 번호 띠(남색 박스 `Ⅱ`) + 제목 + 오른쪽 기관명(작게). 제목 아래 2px 남색 선
- 하단: 왼쪽 출처, 오른쪽 `경상남도 소방본부 119종합상황실 | 쪽번호`
- 1920×1080, 좌우 여백 90px

## 4. 근거 시각화 원칙
- **모든 숫자에 출처**(하단 18px). 추정·설계값은 "(설계)" "(예정)" 표기
- 그래프는 **동향·격차가 보이는 것만**: 시계열 막대/선, 비교 막대(전↔후, 도시↔농촌). 데이터 점이 2개뿐이면 막대 비교로
- 비교 막대: 전/기존 = 회색, 후/우리 = 적색. 축 눈금 최소화, 값은 막대 끝에 직접 표기
- **실제 자료를 화면에 띄운다**: 카카오내비 실제 화면, 공문·보고서 표지, 언론 보도 캡처(제목·출처 보이게, 썸네일 크기, "증빙" 라벨)
- 남의 사진은 크게 쓰지 않는다(보도 캡처는 증빙 썸네일로만)
