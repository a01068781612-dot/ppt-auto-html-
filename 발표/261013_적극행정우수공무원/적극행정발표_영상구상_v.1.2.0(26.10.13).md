## 🎬 영상 2 — "지금, 실제로 작동합니다" (1분 20초)

음악: ①~③은 담담한 비트(작동 화면이 주인공) → 엔딩에서 피아노로 바뀌며 감동

| 구간 | 장면 | 자막 | 소스 |
|---|---|---|---|
| **① 출동 — 실제 구동** 0–22초 | 주행 중 카카오내비 화면 녹화: 일반 안내 → **'띵' "긴급차량 발생 · 263m 뒤에서 접근 중"** → 거리 줄어듦(77m) → (가능하면) 소방차가 옆을 지나가는 차 밖 장면 | *"출동 — 전국 최초, 내비게이션이 먼저 알려 줍니다"* · 카카오내비 · 2026. 4. 20. 서비스 개시 | 실제 화면 녹화(조수석) |
| **② 대응 — 실제 구동** 22–42초 | 농골기 웹페이지 화면 녹화: 마을 이름 입력 → 진입로·회차·주의사항 답 표시(실제 속도) | *"대응 — 239개 마을, 5초면 확인합니다"* · 예산 0원 · 직접 구축 | 실제 화면 녹화 |
| **③ 복구 — 가상 작동** 42–60초 | 원패스 가상화면: 음성 접수("집이 불에 탔어요") → 피해 내용 자동 정리 → 6개 기관 지원이 한 화면에 → **"신청이 완료되었습니다"** · 구석에 "설계 시연 화면" | *"복구 — 한 번의 신청으로, 6개 기관 지원까지"* · *"행정안전부 정부24 개발 착수"* | 모션 가상화면(제작) |
| **엔딩 — 감동** 60–80초 | 음악 끊김, 1초 정적 → 피아노. 검은 화면 위에 한 줄씩 | *"우리는 소방차를 더 사지 않았습니다."* → *"이미 있던 것을, 사람에게 연결했을 뿐입니다."* → (작게) *"길을 비켜 준 운전자, 처음 가는 마을의 대원, 집을 잃은 주민"* → (크게, 마지막) **"그 1분이, 누군가에게는 평생입니다."** | 모션(글자) |

→ 1초 암전 → 발표자 직접: **"골든타임은 기술이 아니라, 먼저 움직인 사람이 지킵니다. 감사합니다."**

엔딩 배경 선택(강사 결정):
- A. 검은 화면 + 글자만 (가장 담백, 추천)
- B. 상황실 모니터의 실제 차량관제 화면(점들이 움직임) 위에 글자 — 개인정보 가림 필요

## 지킬 것
- ①② **실제 화면 녹화만** 사용(연출·재연 없음). 개인정보(주소·차량번호) 보이면 가림
- ③ 원패스는 **"설계 시연 화면"** 표기, 정부24 문구는 근거대로("개발 착수")
- 방송 뉴스 화면 사용 안 함
