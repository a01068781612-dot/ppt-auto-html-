## 고정되는 틀 (바꾸지 않음)
- 1920×1080, 좌우 여백 110px
- 맨 위 태그줄 `PART n  장 이름`(22px, 자간 넓게) → 제목 66px 900 → 제목 첫 글자 왼쪽 위 사각 장식(sqfix 규칙) → 오른쪽 위 외곽선 영단어(Problem./Connect./Effect./Spread./Thank you.) → y=244 가는 구분선
- 둥근 카드(반경 29px, 1.5px 선), 강조 카드는 4px 강조색 테두리 + 그림자
- 표지: 위 작은 행사명 + 가는 선 → 기관명(강조색) → 큰 제목 2줄(둘째 줄 핵심어 강조색) → 부제 → 왼쪽 아래 발표자 / 오른쪽 사진 모자이크
- 마무리: 큰 메시지 2줄(핵심어 강조색 + 밑줄) + 요약 칩 3 + 오른쪽 아래 발표자

## 색상 (택1)
| 역할 | 기본 다크 | A 화이트+스카이 | B 화이트+네이비 | C 딥블루 |
|---|---|---|---|---|
| 바탕 | #0C0B0B + 방사형 | #FFFFFF | #FFFFFF | #06143F→#1E52E6 그라데이션 |
| 글자 | #F4F4F2 | #111827 | #0F1B3D | #F5F8FF |
| 강조 | #FF5A1F | #2F80ED | #1E3A8A | #7FB2FF |
| 카드 | #1D1A19 | #F3F6FB | #F2F4F9 | 흰색 8% |
| 선 | #3A3533 | #DCE3EE | #D9DFEA | 흰색 18% |
- 공통: 문제 그래프의 진입 불가 = 빨강(#FF4D4F), 가능 = 초록(#2FBF5B)

## 레퍼런스에서 가져온 구도
- 표지 오른쪽 둥근 사진 모자이크(실제 사진 3장)
- 4p 층 쌓기(이미 있던 것 → + 새로 더한 것 → 결과)
- 7p 사진 줄(경남에서 증명, 실제 사진 3장) + 아래 타임라인(전국 확산)
