## 1. 한 줄 메시지
> **"골든타임은 세 번 늦어집니다. 우리는 예산 0원으로, 세 번 모두 앞당겼습니다."**

- 뼈대: **문제 3개(늦게 알게 되는 순간) → 해결 3개(출동·대응·복구) → 숫자 → 확산**
- 반복 장치: 숫자 **0** — 예산 0원 · 외주 0건 · 서류 0건 (심사위원 기억에 남길 단어)

## 2. 오프닝 — 임팩트 (첫 15초)
**검은 화면에 실제 카카오내비 알림이 '띵' 하고 내려온다.**
```
🚨 긴급차량 발생 · 263m 뒤에서 접근 중        (알림 팝업)
🚨 긴급차량 발생 ·  77m 뒤에서 접근 중        (거리 숫자 카운트다운 263 → 77)
            ↓
   "사이렌보다 먼저, 내비게이션이 알려 줍니다."
   "올해 4월 20일, 경남에서 전국 최초로."
```
- 실제 서비스 화면(본인 기관 자료)이라 저작권 문제 없음, '진짜 됐다'가 첫 장면에서 증명됨
- 대안 B: 검은 화면 + 숫자 세 개가 차례로 쾅 → `6개 기관 · 8번 방문 · 14일` (복구의 고통으로 시작)
- 추천: **A(내비 알림)** — 도민이 바로 이해하는 장면, "전국 최초"가 첫 10초에 나옴

## 4. 심사 기준 ↔ 화면 대응
| 심사 기준 | 화면 |
|---|---|
| 확산 가능성 (발표 30%) | 10장 전체 + 5장 "전국 최초" + 9장 정부24 |
| 도민체감도 (모니터링단) | 1장 실제 알림, 5장, 9장 서류 0건·음성접수 |
| 적극성·창의성 | 4장 0원·0건, 6장 협업, 8장 검증 |
| 발표 완성도 | 오프닝 훅 · 한 줄 메시지 반복 · 5분 안 |
| 행정효율·공공서비스 질 (선발요건) | 7·8·9장 숫자 |

## 5. 주의할 점
- **기 수상 사례 제외 규정**: 길라잡이(소방청장상)·원패스(행안부장관상)는 이미 수상 → 화면에서 "수상 이후 새 성과"(고도화, 정부24 개발 착수, 내비 전국 확산)와 "세 단계를 묶은 통합 사례"임을 분명히. 11장은 '자랑'이 아니라 '외부 검증'으로 짧게.
- 원패스 수치(1회·7분·서류 0건)는 **설계 기준** → 화면에 "설계" 표기 유지(과장 금지).
- 언론 보도: 캡처·사진 없이 제목·출처 텍스트만.
